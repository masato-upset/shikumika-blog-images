# 納品形式

最初に、生成した画像枚数と保存先を簡潔に示す。その後、記事内の表示順に次をまとめる。

| 項目 | 内容 |
| --- | --- |
| 画像 | `01_内容.png` |
| 挿入位置 | 「本文に実在する一文」の直後。必要に応じて次の見出しも記載 |
| 理由 | この位置で画像が理解を助ける理由 |
| 伝える結論 | 画像1枚で伝える内容を1文で記載 |
| 図解形式 | フロー図、比較図、役割分担図など |
| alt案 | 画像の意味が具体的に伝わる短い文章 |

画像リンクまたはローカルファイルへのリンクを各項目へ付ける。

## 既存画像の扱い

既存画像やスクリーンショットがある場合は、最後に以下のいずれかを明記する。

- 残す
- 新しい図解へ置き換える
- 内容が重複するため削除候補

理由も一文で添える。ユーザーの明示的な依頼なしに、原稿や既存画像そのものを削除しない。

## 生成できなかった場合

画像生成機能がない環境では、各画像について上記項目に加え、そのまま生成機能へ渡せるプロンプトを記載する。生成していない画像を「完成」と表現しない。
